# บันทึกการใช้งานปัญญาประดิษฐ์ (AI Usage Log)

**ชื่อโปรเจกต์:** ศูนย์รวมข้อมูล OTOP และหัตถกรรมพื้นบ้านจังหวัดบุรีรัมย์  
**รายวิชา:** การพัฒนาเว็บไซต์ (Web Development)  

---

## รายการที่ 1: การออกแบบโครงสร้างเว็บไซต์และกำหนดขอบเขตโปรเจกต์

* **วัตถุประสงค์:** คิดไอเดียหัวข้อโปรเจกต์และวางโครงสร้างหน้าเว็บให้สอดคล้องกับโจทย์
* **Prompt ที่ใช้:**
  > "ให้พัฒนาเว็บไซต์ 'ศูนย์รวมข้อมูลท่องเที่ยวชุมชนจังหวัดบุรีรัมย์' (หรือหัวข้อเทียบเท่าที่ผู้สอนอนุมัติ เช่น ร้านกาแฟ ร้านหนังสือ คลินิกสัตว์เลี้ยง) มีหัวข้ออื่นที่คล้ายกันยกมาไหม"
* **ผลลัพธ์ที่ได้จาก AI:**
  AI แนะนำไอเดีย "ศูนย์รวมข้อมูลสินค้า OTOP และหัตถกรรมพื้นบ้าน (Local Crafts & OTOP Directory)" พร้อมเสนอโครงสร้างฟังก์ชั่นหลัก ได้แก่ หน้าแรก (Home), หน้ารายการสินค้า (Listing) และหน้าติดต่อเรา (Contact)
* **สิ่งที่นักศึกษาแก้ไข/ปรับปรุงเอง:**
  * เลือกหัวข้อ OTOP บุรีรัมย์ นำไปเสนออาจารย์ผู้สอนเพื่อขออนุมัติโปรเจกต์
  * ปรับเปลี่ยนหมวดหมู่สินค้า OTOP ให้เน้นเฉพาะภูมิปัญญาเด่นของจังหวัดบุรีรัมย์จริง เช่น ผ้าซิ่นตีนแดง อ.พุทไธสง และเสื่อกก อ.นางรอง

## รายการที่ 2: การพัฒนาส่วนเชื่อมต่อ API (Open-Meteo) และการจัดการข้อผิดพลาด (Error Handling)

* **วัตถุประสงค์:** ดึงข้อมูลสภาพอากาศสาธารณะมาแสดงบนหน้าเว็บด้วย `async/await` พร้อมรองรับ Loading State และ Error Handling
* **Prompt ที่ใช้:**
  > "การเชื่อมต่อ API: ดึงข้อมูลจาก API สาธารณะอย่างน้อย 1 แหล่งด้วย fetch() หรือ axios — แนะนำ Open-Meteo (ไม่ต้องใช้ API key) แสดงข้อมูลบนหน้าเว็บ พร้อมสถานะ Loading และจัดการข้อผิดพลาด (error handling) เมื่อเรียกไม่สำเร็จ ใช้ async/await หรือ Promise"
* **ผลลัพธ์ที่ได้จาก AI:**
  AI เขียนสคริปต์ JavaScript (`listing.js`) สำหรับดึงข้อมูลอุณหภูมิและความเร็วลมจาก Open-Meteo API โดยใช้พิกัดของจังหวัดบุรีรัมย์ พร้อมแสดงข้อความ "กำลังโหลด..." และการใช้ `try...catch`
* **สิ่งที่นักศึกษาแก้ไข/ปรับปรุงเอง:**
  * ปรับพิกัด ละติจูด-ลองจิจูด ให้ตรงกับตัวเมืองบุรีรัมย์ (`latitude=14.993&longitude=103.102`)
  * ปรับโครงสร้าง HTML การ์ดแสดงสภาพอากาศให้เข้ากับดีไซน์โทนสี Amber/Stone ของเว็บไซต์
  * ปรับเปลี่ยนวิธีการจัดการข้อมูลสินค้า OTOP โดยฝังข้อมูลลงใน JavaScript เพื่อแก้ปัญหา CORS Error เมื่อดับเบิลคลิกเปิดไฟล์ผ่านโปรโตคอล `file://`

## รายการที่ 3: การปรับแต่ง UI/UX, Responsive Design และการรองรับ SEO

* **วัตถุประสงค์:** ปรับแต่งส่วนหัวของไฟล์ HTML (`<head>`) ให้รองรับ SEO, Accessibility (Focus States) และการแสดงผล Responsive บนมือถือ
* **Prompt ที่ใช้:**
  > "SEO เบื้องต้น: <title> และ <meta name='description'> ไม่ซ้ำกันในแต่ละหน้า มี h1 เพียงหนึ่งเดียวต่อหน้า รูปภาพทุกรูปมี alt มี Open Graph meta อย่างน้อย 2 ตัว และรองรับ Responsive Design 3 ขนาด"
* **ผลลัพธ์ที่ได้จาก AI:**
  AI เจเนอเรตแท็ก Meta, Open Graph, ฟอนต์ Sarabun, การตั้งค่า Tailwind CSS และโครงสร้าง HTML5 Semantic Tags
* **สิ่งที่นักศึกษาแก้ไข/ปรับปรุงเอง:**
  * เขียนข้อความ `<title>` และ `<meta name="description">` ใหม่ให้มีคีย์เวิร์ดเฉพาะตรงตามเนื้อหาของแต่ละหน้า (Home, Listing, Contact)
  * ตรวจสอบความถูกต้องของลำดับชั้น Heading (`<h1>` -> `<h2>` -> `<h3>`) ด้วย W3C HTML Validator และแก้ไขจุดที่ลำดับข้ามชั้น
  * ทดสอบการแสดงผลบนสมาร์ตโฟนผ่าน Chrome DevTools (Device Toolbar) และปรับเปลี่ยนขนาด Padding/Margin บนหน้าจอมือถือไม่ให้เกิดการเลื่อนแนวนอน (Horizontal Scroll)
